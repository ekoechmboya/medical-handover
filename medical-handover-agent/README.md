# Medical Handover Quality Benchmark

Synthetic benchmark for evaluating whether an AI system can identify clinically important information that is omitted, only partially communicated, or incorrectly represented in a shift handover.

## Cases

- Cases 01-05: Easy
- Cases 06-10: Medium and higher-complexity cases

Each case contains synthetic records, a current handover, and machine-readable ground truth.

## Important

All records are fictional and synthetic. They are designed for engineering evaluation and are not medical advice or real patient records.
